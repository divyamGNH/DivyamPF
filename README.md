## ✨ Features

- **Interactive 3D Elements**: Powered by Three.js for a more engaging experience.
- **Smooth Animations**: Integrated with Framer Motion for seamless page transitions and micro-interactions.
- **Fully Responsive**: Designed with Tailwind CSS to look great on desktop, tablet, and mobile.
- **Dynamic Content Management**: Utilizing Zustand for lightweight global state management.

## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/divyamGNH/DivyamPF.git
   cd DivyamPF
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. Open your browser and visit `http://localhost:5173`
